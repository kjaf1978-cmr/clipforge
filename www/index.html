Guide – what the settings mean

Format = container + codec

A video file is a container (the "box", recognised by the file ending such as .mp4) holding a video stream and an audio stream. Each stream is compressed by a codec (coder/decoder – the method used to shrink the pictures or sound). Converting changes the box and, usually, re-compresses the streams.

Compression modes

  • Quality – you choose how good the picture should be (0–100 %); the file becomes as small as possible for that quality. The final size depends on the video content (a static lecture compresses far more than football).
    Internally 100 % ≈ CRF 18 (visually lossless) and 0 % ≈ CRF 40 (very blurry). CRF = Constant Rate Factor, the quality number of the H.264/VP8 encoders; lower CRF = better quality, larger file. For WMV/AVI/MPG the equivalent "q-scale" 2 (best) … 31 (worst) is used.
  • Target size – you enter the size you need in MB (e.g. 16 MB for an email/WhatsApp limit). The app computes the bitrate (data per second, in kbit/s = kilobits per second) from: (target size × 8) ÷ duration − audio bitrate. Results usually land within ±8 % of the target; if the first attempt is too big, the app automatically re-encodes with a lower bitrate (up to 3 passes) and, for very small targets, lowers the resolution so the picture stays clean. A target larger than the original is capped at 95 % of the original size.
  • Copy streams – changes only the container, without re-compressing (seconds instead of minutes, no quality loss, same size). Only works if the target container supports the original codecs (e.g. MKV→MP4 with H.264 inside). If it fails, use Quality mode.

Other settings

  • Resolution – size of the picture's short side in pixels (the height of a landscape video, the width of an upright phone video): 1080p = 1920×1080 (Full HD), 720p = 1280×720 (HD), 480p ≈ 854×480 (DVD-like), 360p ≈ 640×360. Halving the height roughly quarters the pixels and is the strongest size reducer. Videos are never enlarged.
  • Frame rate (fps) – pictures per second. 30 fps looks smooth; 24 is cinema; 15 is fine for screen recordings/slides and saves space.
  • Audio bitrate – 128 kbit/s = good music quality; 96 = good speech/music; 64 = speech only. "Remove audio" makes a silent video.
  • Encoder speed (MP4/MKV/MOV/FLV/3GP) – slower settings produce ~10–20 % smaller files at equal quality but take 2–4× longer.

Limits

Conversion runs inside your browser, without internet and without uploading anything. It uses one processor core, so expect roughly 0.3–1× real-time for 720p (a 10-minute 720p video ≈ 10–30 min). Files up to about 1.5 GB work on a PC; on a phone keep to a few hundred MB. Copy-mode is always fast.
